Second public release of **raft-devin-adapter**, an experimental ACP compatibility adapter for running Devin CLI as an internal Raft agent through the existing Grok Build runtime slot — now on **Windows and Linux**.

第二个公开版本：实验性 ACP 适配器，通过 Raft 已有的 Grok Build 入口把 Devin CLI 接为内部 Agent；新增 Linux 支持与 Docker 开发验证环境。

- Linux launcher + `~/.local/bin/grok` install path matching Raft's POSIX discovery (`which` fallback), generated by POSIX shell scripts under `platform/linux/`.
- Repository restructure: OS entry points grouped under `platform/{windows,linux}/`.
- `authenticate` pass-through for Devin distributions that require host-side ACP authentication, plus clearer unauthenticated-launch diagnostics.
- Standalone Devin CLI discovery on POSIX (`~/.local/bin/devin` and its `_versions/current` target).
- `docker/` sandbox: Node 22 + official Devin CLI, optional Raft Computer; `docker build` runs the full offline suite, the launcher chain through PATH `grok`, and a real `devin acp` handshake — no inference.
- CI: both launchers built and smoke-tested; Docker image build verified.

Validated: offline protocol suite on Node 22/24 for Windows and Linux; the full bridge chain against real Devin CLI 3000.12.32 inside the Linux image; **live end-to-end on a real Raft server** — Raft Computer 1.0.67 detected the `grok` slot, populated the agent's model list through the adapter, spawned it via `agent --no-leader --always-approve stdio`, and a DM produced a real inference reply. Cross-computer migration and Windows live inference remain unverified.

The Raft UI still shows Grok Build; a real Grok installation cannot directly share that slot. Grok account widgets and native transcript export are not implemented. Future upstream protocol changes may require updates.

Start with [English setup](https://github.com/sealpp/raft-devin-adapter) or [中文说明](https://github.com/sealpp/raft-devin-adapter/blob/main/README.zh-CN.md). Download the source or clone the repository, then build locally; this release does not bundle vendor binaries or a precompiled launcher.
