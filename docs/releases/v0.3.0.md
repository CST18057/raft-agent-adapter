Experimental ACP compatibility adapter that runs Devin CLI or DeepSeek Harness as an internal Raft agent through the existing Grok Build runtime slot, on **Windows and Linux**. The project is renamed to **raft-agent-adapter**.

实验性 ACP 适配器：通过 Raft 已有的 Grok Build 入口，把 Devin CLI 或 DeepSeek Harness 接为内部 Agent，支持 Windows 与 Linux。项目更名为 raft-agent-adapter。

- `backend` setting selects Devin CLI (the default when installed) or DeepSeek Harness (`dsh acp`). Backend differences are isolated in `src/backends.mjs`.
- DeepSeek Harness: `session/load` maps to `session/resume`, `session/delete` to `session/close`, grouped model options are flattened, `reasoning_effort` maps to Raft's reasoning effort, and interjections sent during a turn are delivered as the next prompt.
- Linux launcher and `~/.local/bin/grok` install path matching Raft's POSIX discovery, with `platform/linux/` install, uninstall, refresh and test scripts.
- Repository restructure: OS entry points grouped under `platform/{windows,linux}/`.
- `authenticate` pass-through for Devin distributions that require host-side ACP authentication, plus clearer unauthenticated-launch diagnostics.
- Standalone Devin CLI discovery on POSIX (`~/.local/bin/devin` and its `_versions/current` target).
- `docker/` sandbox: Node 22 with the official Devin CLI, optional Raft Computer. The build runs the offline suite and the launcher chain through PATH `grok`.
- CI: both launchers built and smoke-tested; Docker image build verified.

Validated: the offline protocol suite, and the full launcher chain through PATH `grok` against both fake peers, plus the uninstall/reinstall cycle. Live Devin validation (Raft Computer 1.0.67 detected the `grok` slot, the adapter populated the agent's model list, and a DM produced a real inference reply) was recorded before the multi-backend refactor and has not been repeated since. DeepSeek Harness has not been run against a real `dsh` binary. Cross-computer migration and Windows live inference remain unverified.

The Raft UI still shows Grok Build; a real Grok installation cannot directly share that slot. Grok account widgets and native transcript export are not implemented. Future upstream protocol changes may require updates.

Start with [English setup](https://github.com/sealpp/raft-agent-adapter) or [中文说明](https://github.com/sealpp/raft-agent-adapter/blob/main/README.zh-CN.md). Download the source or clone the repository, then build locally; this release does not bundle vendor binaries or a precompiled launcher.
