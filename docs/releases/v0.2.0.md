First public release of **raft-devin-adapter**, an experimental Windows-first ACP compatibility adapter for running Devin CLI as an internal Raft agent through the existing Grok Build runtime slot.

首个公开版本：通过 Raft 已有的 Grok Build 入口，将 Devin CLI 接为内部 Agent，无需修改 Raft 程序或让 Agent 循环轮询消息。

- Native model discovery and separate thinking selection, including SWE-2 Max.
- Host instruction forwarding, mid-turn messages, permissions, streaming, usage, and same-machine session resume.
- Source-built Windows launcher, local proxy configuration, install/uninstall scripts.
- English/Chinese guides, offline protocol tests, and MIT license.

Validated against Raft Computer 1.0.63 and Devin CLI 3000.12.32 on Windows. The generalized checkout also passed launcher and native configuration-only checks. CI tests protocol behavior on Node 22/24 on Windows/Linux; live non-Windows integration and cross-computer migration remain unverified.

The Raft UI still shows Grok Build; a real Grok installation cannot directly share that slot. Grok account widgets and native transcript export are not implemented. Future upstream protocol changes may require updates.

Start with [English setup](https://github.com/sealpp/raft-devin-adapter#quick-start-on-windows) or [中文说明](https://github.com/sealpp/raft-devin-adapter/blob/main/README.zh-CN.md). Download the source or clone the repository, then build locally; this release does not bundle vendor binaries or a precompiled launcher.
