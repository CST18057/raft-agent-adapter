# Changelog

## 0.3.0 — Linux support and repository restructure

- Add a POSIX launcher (`bin/grok`) generated by `platform/linux/build.sh`; it `exec`s Node so Raft's detached-process shutdown reaches the adapter.
- Add `platform/linux/` install/uninstall/refresh/test scripts; `install.sh` places a `grok` trampoline in `~/.local/bin`, the directory Raft's POSIX discovery falls back to.
- Move Windows entry points to `platform/windows/`; commands and docs updated accordingly.
- Discover the standalone Devin CLI on POSIX at `~/.local/bin/devin` and its `_versions/current` target before PATH.
- Forward ACP `authenticate` to Devin and re-prime after it, for distributions that require host authentication; surface a clearer hint when `session/new` is rejected as unauthenticated.
- Add `docker/` development sandbox (Node 22 + Devin CLI, optional Raft Computer); `docker build` runs the full verification suite including a real `devin acp` handshake.
- CI now builds both launchers, smoke-tests through them against the fake peer, and builds the Docker image.
- Verified live end-to-end on Linux: Raft Computer 1.0.67 attached to a real server detected the `grok` slot, probed models through the adapter, spawned an internal agent on Grok Build, and a DM returned a real Devin inference reply.

## 0.2.0 — First public release

- Connect Devin CLI to Raft's internal-agent Grok Build ACP entry point.
- Translate model choices and independently configurable thinking levels, including SWE-2 Max.
- Forward initial host instructions, mid-turn messages, permission requests, streaming updates, and usage.
- Support same-machine native session resume with history replay suppression.
- Add a source-built Windows stdio launcher, configuration discovery, process-specific proxy settings, and install/uninstall scripts.
- Add independently authored offline protocol tests, Windows/Linux CI, English/Chinese documentation, and MIT licensing.

Experimental Windows-first release. See [compatibility](docs/compatibility.md) for tested versions and limitations. Earlier versions were local experiments and were not published as repository releases.
